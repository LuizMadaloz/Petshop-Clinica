# 🐾 VetPet System - Gestão de Petshop e Clínica Veterinária

> Projeto pessoal de um sistema integrado para gerenciamento completo de Petshops e Clínicas Veterinárias.

Este é um sistema robusto desenvolvido para unificar as necessidades operacionais de um petshop (como banho, tosa e venda de produtos) com os processos críticos de uma clínica médica veterinária (prontuários, consultas e vacinas).

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

*   **Linguagem de Programação:** [JavaScript](https://mozilla.org) (Full-Stack / Node.js)
*   **Banco de Dados:** [MySQL](https://mysql.com) (Banco de dados relacional para consistência de dados críticos)

---

## 📋 Funcionalidades Principais

### 🐕 Módulo Petshop & Clientes
*   **Cadastro de Tutores:** Registro completo de dados dos clientes (nome, contato, endereço).
*   **Cadastro de Pets:** Perfil do animal contendo raça, idade, peso, foto e histórico.
*   **Agenda de Estética:** Marcação e controle de horários para Banho e Tosa.

### 🩺 Módulo Clínica Veterinária
*   **Prontuário Eletrônico:** Histórico médico digitalizado de cada paciente animal.
*   **Consultas e Exames:** Registro de anamnese, diagnósticos e solicitação de exames laboratoriais.
*   **Controle de Vacinas:** Carteira de vacinação digital com alertas de retorno.

### 📊 Módulo Administrativo 
*   **Controle de Estoque:** Gerenciamento de produtos de petshop e medicamentos da clínica.
*   **Fluxo de Caixa:** Registro de vendas de produtos e cobrança de serviços prestados.
